Service identities

Create a token for the browser extension, collection tooling, or automation. The secret is shown once. One case pins the token to a case you administer. All my cases lets the token capture and write to every case where you are an investigator or case administrator, including cases you join later; it stops as soon as you lose that role, the case is closed or archived, or your account is disabled. It can only capture and write, must expire within 90 days, and still needs the case password for a locked case.
